# BlueAudioSwitch

BlueAudioSwitch — небольшая утилита для Windows, которая автоматически выбирает актуальный источник вывода звука в зависимости от того, какие устройства реально подключены.

Вместо того чтобы каждый раз вручную открывать меню звука Windows при подключении колонки, наушников или Bluetooth-устройства, программа сама отслеживает состояние аудиоустройств и переключает выход.

Главное правило простое: **последнее подключённое доступное устройство получает приоритет**. Если оно отключается, BlueAudioSwitch выбирает другое активное устройство, а если внешних устройств не осталось — возвращает звук на встроенные динамики ноутбука.

## Что умеет

- Следит за Bluetooth-аудиоустройствами и физическими событиями их подключения.
- Отдаёт приоритет устройству, которое подключилось последним.
- Автоматически запрашивает переподключение ранее сопряжённых Bluetooth-аудиоустройств.
- Ждёт, пока реальный аудиопрофиль устройства станет активным, и только после этого переключает звук.
- Предпочитает Stereo/A2DP профилю Hands-Free с ухудшенным качеством.
- Переключает сразу все три роли аудио Windows: Console, Multimedia и Communications.
- После отключения текущего устройства возвращается на другое активное устройство.
- Если внешних аудиоустройств больше нет, переключается на встроенные динамики ноутбука.
- Работает в фоне и запускается вместе с Windows.
- Использует только встроенные Windows API, без телеметрии и сетевого доступа.

## Поддержка Dark Project HS5 / DP-HS-1015

Dark Project HS5 — отдельный особый случай. Его 2.4-ГГц USB-донгл постоянно остаётся видимым в Windows как рабочее аудиоустройство даже тогда, когда сами наушники выключены. Поэтому обычная проверка аудиовыхода не позволяет понять, есть ли реальная радиосвязь с гарнитурой.

BlueAudioSwitch добавляет специальную поддержку этого донгла и читает реальный статус 2.4-ГГц соединения через HID:

- HS5 включились и установили радиосвязь -> звук автоматически переключается на `Динамики (DP-HS-1015)`.
- HS5 выключились -> программа перестаёт считать постоянно подключённый донгл актуальным выходом.
- Если последнее Bluetooth-устройство всё ещё подключено, звук возвращается на него.
- Если внешних устройств больше нет, звук переключается на встроенные динамики ноутбука.

То есть поддержка HS5 — это дополнительная специализированная возможность поверх основной логики автоматического переключения аудиоисточников.

## Поддерживаемый донгл HS5

Специальная интеграция сейчас рассчитана на приёмник Dark Project HS5 / DP-HS-1015:

```text
USB VID: 10D6
USB PID: B011
HID usage page: FF90
Input report ID: 55
```

Обычные Bluetooth-аудиоустройства работают через общую логику BlueAudioSwitch. Другие проприетарные 2.4-ГГц донглы не считаются совместимыми с HS5-интеграцией, пока их протокол не проверен отдельно.

## Future / Roadmap

В перспективе поддержка проприетарных аудио-донглов должна стать расширяемой системой, а не набором жёстко зашитых исключений в основном коде.

Планируемое направление:

- **Профили донглов** — отдельные профили по USB `VID/PID` плюс небольшой parser конкретного HID/vendor-отчёта.
- **Универсальное ядро** — основная логика переключения аудио остаётся независимой от модели устройства, а профиль отвечает только на вопрос: есть ли реальная беспроводная связь с гарнитурой.
- **Learning mode** — пользователь несколько раз включает и выключает гарнитуру, программа сравнивает HID-отчёты и помогает определить байт или бит, отвечающий за состояние соединения.
- **Community profiles** — возможность добавлять поддержку новых донглов без изменения основного приложения.
- **HS5 как эталонный профиль** — `VID_10D6&PID_B011` остаётся первым проверенным примером и шаблоном для интеграции других приёмников.

Цель не в том, чтобы считать все USB-аудиодонглы одинаковыми. Идея — одно универсальное ядро BlueAudioSwitch и небольшие адаптеры для проприетарных протоколов конкретных приёмников.

## Установка

1. Скачай архив со страницы [Releases](../../releases/latest).
2. Распакуй его в обычную папку.
3. При желании сначала запусти `Test.cmd`, чтобы посмотреть работу без установки.
4. Запусти `Install.cmd`.

Рабочая копия устанавливается сюда:

```text
%LOCALAPPDATA%\BlueAudioSwitch
```

После установки BlueAudioSwitch запускается автоматически вместе с текущим пользователем Windows. Права администратора не нужны.

## Удаление

Запусти `Uninstall.cmd`. Он удалит запись из автозагрузки и установленную копию программы.

## Как HS5 сообщает состояние

У приёмника DP-HS-1015 есть служебная HID-коллекция. При изменении 2.4-ГГц радиосвязи донгл отправляет 64-байтный HID-отчёт:

```text
55 6B 00 ... DP-HS-1015  # наушники подключились
55 6B 01 ... DP-HS-1015  # наушники отключились
```

Байт 2 содержит состояние: `00` — подключено, `01` — отключено. BlueAudioSwitch только читает эти события и не отправляет неизвестные команды донглу и не изменяет прошивку.

Подробности захвата и проверки протокола находятся в [docs/protocol.md](docs/protocol.md).

## Если не работает

### Bluetooth-устройство не становится активным выходом

Проверь, что оно сопряжено и действительно подключено в Windows. Не все Bluetooth-драйверы одинаково обрабатывают программный запрос переподключения, поэтому отдельные OEM-драйверы могут его игнорировать, хотя ручное подключение работает нормально.

Журнал программы находится здесь:

```text
%LOCALAPPDATA%\BlueAudioSwitch\BlueAudioSwitch.log
```

### HS5 не вызывает переключение

Проверь, что в диспетчере устройств отображается `DP-HS-1015` и USB ID приёмника равен `VID_10D6&PID_B011`.

При обычном включении и выключении HS5 в журнале должны появляться строки с:

```text
DP-HS-1015 connected (HID 55-6B-00).
DP-HS-1015 disconnected (HID 55-6B-01).
```

## Конфиденциальность и безопасность

BlueAudioSwitch читает локальное состояние аудиовыходов, состояние Bluetooth-подключений и HID-отчёт HS5, если такой донгл присутствует. Программа не записывает звук, не подключается к интернету, не собирает аналитику, не прошивает донгл и не отправляет неизвестные vendor-команды.
