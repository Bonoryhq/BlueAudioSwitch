# BlueAudioSwitch

BlueAudioSwitch — утилита для автоматического переключения аудиовыходов по факту подключения устройств.

Главное правило простое: **последнее подключённое доступное устройство получает приоритет**. Если оно отключается, BlueAudioSwitch выбирает другой доступный внешний выход, а если внешних устройств больше нет — возвращает звук на встроенные динамики компьютера.

Цель проекта — вообще убрать ручное открытие меню звука и выбор выхода.

## Платформы

### Windows

Windows-версия находится в корне репозитория и использует PowerShell плюс нативные Windows API для аудио, Bluetooth и HID.

Сейчас это наиболее полная реализация: есть автоматические запросы переподключения Bluetooth, предпочтение Stereo/A2DP и проверенный профиль Dark Project HS5.

Установка: `Install.cmd`. Для проверки без установки можно запустить `Test.cmd`.

### macOS

Нативная версия на Swift находится в [`macos/`](macos/README.md).

Она использует:

- **Core Audio** для обнаружения и переключения аудиовыходов;
- **IOKit / HID** для проприетарных беспроводных донглов;
- **LaunchAgent** для фонового автозапуска.

Текущая macOS-версия умеет отслеживать Bluetooth, USB, AirPlay, HDMI и другие внешние Core Audio-выходы, переключаться на последнее доступное устройство, возвращаться на другой активный источник и в крайнем случае — на встроенные динамики Mac. Профиль HS5 также перенесён на macOS.

## Основная логика

- Определять доступные аудиовыходы.
- Запоминать, какое внешнее устройство стало доступно последним.
- Автоматически переключаться на последнее подключённое внешнее устройство.
- После его отключения выбирать другой доступный внешний источник.
- Если внешних источников не осталось — переключаться на встроенные динамики.
- Не мешать ручному выбору пользователя до следующего реального события подключения устройства.
- Работать локально, без телеметрии и облачных сервисов.

Глубокая device-specific логика подключается только там, где обычного состояния аудиовыхода операционной системы недостаточно.

## Проприетарные 2.4-ГГц донглы

Некоторые USB-аудиодонглы продолжают отображаться как рабочее аудиоустройство даже тогда, когда беспроводная гарнитура за ними выключена. В таком случае ОС видит сам донгл, но не знает реального состояния радиосвязи.

BlueAudioSwitch решает это через небольшие профили устройств, которые отвечают на один вопрос:

> Есть ли прямо сейчас реальная беспроводная связь с гарнитурой?

Основное ядро переключения остаётся универсальным, а специфичной является только логика чтения конкретного HID/vendor-протокола.

## Dark Project HS5 / DP-HS-1015

HS5 — первый проверенный профиль проприетарного донгла.

```text
USB VID: 10D6
USB PID: B011
HID usage page: FF90
Input report ID: 55
```

Наблюдаемые HID-отчёты состояния:

```text
55 6B 00 ... DP-HS-1015  # подключено
55 6B 01 ... DP-HS-1015  # отключено
```

Когда радиосвязь появляется, BlueAudioSwitch может выбрать выход HS5. Когда связь пропадает, постоянно присутствующий USB-донгл перестаёт считаться рабочим назначением и включается обычная fallback-логика.

Подробности протокола находятся в [docs/protocol.md](docs/protocol.md).

## Future / Roadmap

Долгосрочная цель — единое универсальное ядро переключения с небольшими адаптерами для проприетарных беспроводных приёмников.

План:

- **Профили донглов** по USB `VID/PID` плюс небольшой HID/vendor parser.
- **Общее dongle-ядро** для Windows и macOS.
- **Learning mode** — несколько циклов ON/OFF с автоматическим сравнением HID-отчётов для поиска байта или бита состояния соединения.
- **Community profiles** — добавление новых донглов без изменения основного switching engine.
- **HS5 как эталонный профиль** — первый полностью проверенный пример.

Проект не предполагает, что все USB-аудиодонглы используют один и тот же протокол.

## Установка Windows

1. Скачай ZIP со страницы [Releases](../../releases/latest).
2. Распакуй архив.
3. При желании сначала запусти `Test.cmd`.
4. Запусти `Install.cmd`.

Рабочая копия устанавливается сюда:

```text
%LOCALAPPDATA%\BlueAudioSwitch
```

Удаление: `Uninstall.cmd`.

## Установка macOS

Подробности находятся в [`macos/README.md`](macos/README.md).

Быстрая установка из исходников:

```bash
cd macos
chmod +x install.sh uninstall.sh
./install.sh
```

macOS-версия написана нативно на Swift. Electron и отдельное приложение в menu bar для работы не требуются.

## Конфиденциальность и безопасность

BlueAudioSwitch читает только локальное состояние аудиоустройств и, для поддерживаемых проприетарных донглов, локальные HID-отчёты состояния соединения.

Программа не записывает аудио, не собирает аналитику и не отправляет данные в облако. Интеграция HS5 только читает известные HID-события и не отправляет неизвестные vendor-команды и не изменяет прошивку.
